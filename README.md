Выбран датасет Mushroom Classification, потому что на нем можно исследовать влияние признаков гриба на его ядовитость и сравнить несколько моделей классификации

Гипотезы:
1. Запах — самый информативный признак для определения ядовитости гриба.
2. Размер пластинок и цвет спор сильно связаны с ядовитостью гриба.
3. Логистическая регрессия сможет получить F1 выше 0.95.
4. Random Forest покажет качество не хуже логистической регрессии.
5. Подбор гиперпараметров улучшит качество логистической регрессии.
6. Запах окажется самым важным признаком и для обученной модели.

Результаты:
Все 6 гипотез подтвердились:  
    Запах оказался самым информативным признако  
    Размер пластинок и цвет спор тоже показали сильную связь с ядовитостью  
    Логистическая регрессия получила F1 = 0.9994 на кросс-валидации  
    Random Forest получил F1 = 1.0  
    После подбора гиперпараметров логистическая регрессия тоже достигла F1 = 1.0  
    Для обученной модели запах тоже самый важный признак
